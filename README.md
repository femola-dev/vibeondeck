# vibeondeck

Practicing developing a dead simple portfolio page.

## Layout Practice - Icon Navigation

A smooth icon navigation bar with a sliding background indicator that follows your cursor as you hover between buttons.

### Features

- Smooth sliding background indicator on hover
- Indicator returns to the active button when the mouse leaves
- Click to set active state
- Tooltip labels on hover
- Responsive design
- Accessible focus states

### Getting Started

```bash
npm install
npm run dev
```
